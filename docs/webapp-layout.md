# stock-god Web 工作台布局图（当前实现）

> 对应提交 b8ddfff（feature/stock-webapp）。本文为布局现状的详细示意图，供确认与标注后续调整项。
> 页面入口：`http://127.0.0.1:8000/`（纯前端布局，刷新即生效，无需重启服务）。

## 1. 整体框架（路由 `/`，组件 Workbench.vue）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  stock-god 股票                                                ← 全局顶栏(约48px) │
├──────────────────────────────┬─╌╌╌─┬──────────────────────────┬───────────────┤
│                              │     │                          │ 任务中心    » │ ←侧栏头
│  [全部] [收藏]   ┌──────────┐│     │  [← 返回] AAPL — 苹果      │───────────────│
│                  │ 搜索框…   ││  拖 │  ✎别名 （别名：Google）    │ #12 下载 NKE  │
│                  └──────────┘│  替 │  [同步股票列表 →移至左栏?] │    运行中 [取消]│
│  ┌──────────────────────────┐│  条 │                          │ #13 分析 AAPL │
│  │代码  公司    市场 已下载 操作││     │  [下载财报][生成分析][DCF估值]│    排队    [取消]│
│  │──────────────────────────││     │  ┌──────────────────────┐│ #11 下载 MSFT │
│  │AAPL  苹果   US   23  ☆ …││     │  │ 财报 | 分析 | 图表 | DCF ││    成功       │
│  │MSFT  微软   US   14  ★  ││     │  └──────────────────────┘│ #10 DCF  NKE  │
│  │GOOGL 谷歌   US   22  ★  ││     │   （中栏详情，见 §3）      │    失败 [SEC_…]│
│  │ …                       ││     │                          │  └ 点行展开日志 │
│  └──────────────────────────┘│     │                          │───────────────│
│  ‹上一页  第1页/共209页  下一页›│     │                          │  全部任务 →    │
│  （左栏 StockList，见 §2）     │     │                          │ （右栏，见 §4） │
└──────────────────────────────┴─────┴──────────────────────────┴───────────────┘
     默认 420px（可拖拽）        ~6px   自适应剩余宽度              默认 280px
```

- 顶栏全宽，`/`（工作台）与 `/tasks`（全页）共用
- 分隔条：6px，`col-resize` 光标，拖拽范围 240px ~ 60vw，宽度存浏览器 localStorage（`sg.workbench.leftWidth`），刷新记忆
- 中栏无详情时显示空态："在左侧点击股票查看详情"

## 2. 左栏：股票列表（StockList.vue）

```
┌────────────────────────────────────────────┐
│ ┌──────┐┌──────┐                           │
│ │ 全部 ││ 收藏 │   ← 视图 Tab（蓝色=激活）    │
│ └──────┘└──────┘                           │
│ ┌────────────────────────────┐ ┌────────┐ │
│ │ 搜索代码/公司名/别名（支持中文）│ │同步股票列表│ │ ← 搜索300ms防抖；同步建后台任务
│ └────────────────────────────┘ └────────┘ │
│ 代码    公司       市场  已下载财报  操作      │
│ ─────────────────────────────────────────  │
│ AAPL   苹果      US     23      ☆ [下载][分析][DCF]
│ MSFT   微软      US     14      ★ [下载][分析][DCF]
│ GOOGL  谷歌      US     22      ★ [下载][分析][DCF]
│ TSLA   特斯拉    US      0(未下载) ☆ [下载][分析][DCF]
│   …（每页 50 条，后端分页）                   │
│ （无匹配时：无匹配股票 / 暂无收藏，在列表中点击★收藏）│
│                                            │
│ ‹上一页   第 1 页 / 共 209 页（10422 只）  下一页›│
└────────────────────────────────────────────┘
```

交互：
- 点整行 → 中栏打开该股详情
- ★/☆ → 收藏/取消（行内即时更新；收藏视图取消后该行移除、页码自动回退）
- [下载]=years 5，[分析]=默认参数，[DCF]=脚本默认参数 → 直接建后台任务（toast 提示；重复提交被 409 拦截提示"已有同类型任务进行中"；提交中按钮禁用）
- 已下载财报数为 0 时显示灰色"未下载"

## 3. 中栏：个股详情（StockDetail.vue，路由 /stocks/{ticker}）

```
┌──────────────────────────────────────────────────────┐
│ [← 返回]  AAPL — 苹果   ✎别名  （别名：Google / 苹果公司）│
│          ↑回工作台空态   ↑行内编辑，保存即生效          │
│                                                      │
│ [下载财报]  [生成分析]  [DCF 估值]   ⟳ 下载财报 #12 进行中│

```
│ 类型   期间        下载时间           文件              │

│ 10-K   2024-09-29  2026/9/16 10:23  [打开] [下载]      │

## 4. 右栏：任务中心侧栏（TaskSidebar.vue）

### 展开态（默认 280px）

```
┌───────────────────────────┐
│ 任务中心               [»] │  ← [»] 折叠成细条
│───────────────────────────│
│ #12 下载财报 NKE   运行中 [取消]│ ← 点行展开/收起日志（互斥）
│  ┌──────────────────────┐ │
│  │ (深色终端风实时日志)    │ │  ← 排队/运行中时 2s 自动追加
│  │ ...                  │ │
│  └──────────────────────┘ │
│ #13 财报分析 AAPL   排队  [取消]│
│ #10 DCF估值 NKE    成功    │
│ #9  下载财报 MSFT  失败    │ ← 展开时顶部红条：
│  ┌──────────────────────┐ │    [SEC_RATE_LIMITED] SEC 限流…
│  │[SEC_RATE_LIMITED] …  │ │
│  │ (日志)                │ │
│  └──────────────────────┘ │
│  …（最多显示最近 20 条）     │
│───────────────────────────│
│ 全部任务 →                 │ ← 进入 /tasks 全页
└───────────────────────────┘
```

### 折叠态（36px 细条）

```
┐
│ ●          ← 红点：有运行中/排队任务时显示
│ 任
│ 务
│ 中
│ 心        ← 竖排文字，点击展开
│
┘
```

- 状态徽标颜色：排队/运行中=蓝，成功=绿，失败=红，已取消=灰
- 折叠状态存 localStorage（`sg.sidebar.collapsed`），刷新记忆
